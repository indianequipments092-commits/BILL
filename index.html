Install kaise karein (Android)

  1. Download button dabayein. Browser puchhe to Download anyway chunein.
  2. Download hui file kholein. Settings aaye to is browser ko Install allow kar dein. Play Protect dikhe to More details → Install anyway.
  3. App kholein aur apne account se Login karein. Aage se update apne aap milega.

iPhone par app jaisa chalayein

  1. iPhone ke Safari mein iebilling.pages.dev/billing kholein.
  2. Neeche Share icon dabayein.
  3. Add to Home Screen chunein, phir Add. Ab ye home screen se app ki tarah khulega.

iPhone par APK file nahi chalti, isliye ye tareeka hai. Install nahi karna padta aur update apne aap milta hai. Safari me hi kholein (Chrome me ye option nahi aata).
